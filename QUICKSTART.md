# ⚡ Quick Start (5 minutos)

Siga isso rápido:

## 1️⃣ Configure Credenciais

Arquivo `.env`:
```
VITE_SUPABASE_URL=https://seu_projeto.supabase.co
VITE_SUPABASE_ANON_KEY=sua_anon_key
```

Pega em: https://supabase.com > seu projeto > Settings > API

## 2️⃣ Crie as Tabelas

1. Supabase > SQL Editor > New Query
2. Copie tudo de `supabase/schema.sql`
3. Paste > Run

## 3️⃣ Rode Local

```bash
npm install
npm run dev
```

Vai abrir em `http://localhost:3000`

## 4️⃣ Teste Agora

- **Cadastro:** Cria conta com email/senha
- **Agenda:** Agende uma consulta
- **Verificar:** Vá em Supabase > Table Editor > appointments > vê sua consulta lá?
